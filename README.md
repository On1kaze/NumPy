### Задание 3. Свойства массива
> **Условие:** Для массива ниже определите без запуска программы значения `ndim`, `shape`, `size` и `dtype`. Затем проверьте ответ в Python.
> ```python
> a = np.array([[3, 6, 9],
>               [12, 15, 18]])
> ```

#### 🧠 Теоретическое определение (без запуска):
1. **`ndim` (размерность / число измерений):** `2`
   - Массив двумерный (матрица: содержит строки и столбцы).
2. **`shape` (форма массива):** `(2, 3)`
   - Матрица состоит из 2 строк и 3 столбцов.
3. **`size` (общее число элементов):** `6`
   - Количество элементов вычисляется как произведение измерений: $2 \times 3 = 6$.
4. **`dtype` (тип данных элементов):** `int32` / `int64`
   - Все элементы являются целыми числами без плавающей точки, по умолчанию NumPy создает целочисленный тип.

#### 💻 Проверка в Python:
```python
print("a.ndim:", a.ndim)    # 2
print("a.shape:", a.shape)  # (2, 3)
print("a.size:", a.size)    # 6
print("a.dtype:", a.dtype)  # int64 (или int32 в зависимости от платформы)
```

### Задание 4. Индексы
> **Условие:** Дан массив `numbers`. Выведите первый, третий и последний элементы. После этого замените число 30 на 100.
> ```python
> numbers = np.array([10, 20, 30, 40, 50])
> ```

```python
import numpy as np

numbers = np.array([10, 20, 30, 40, 50])

# Первый элемент (индекс 0)
first = numbers[0]    # 10

# Третий элемент (индекс 2)
third = numbers[2]    # 30

# Последний элемент (индекс -1)
last = numbers[-1]    # 50

# Замена числа 30 на 100 (находится под индексом 2)
numbers[2] = 100
```
**Вывод:**
```text
Первый: 10
Третий: 30
Последний: 50
После замены: [ 10  20 100  40  50]
```

### Задание 5. Срезы
> **Условие:** Из массива `numbers` получите:
> - а) элементы с индексами от 1 до 3;
> - б) первые три элемента;
> - в) элементы начиная с индекса 2.

```python
import numpy as np

numbers = np.array([10, 20, 30, 40, 50])

# а) Элементы с индексами от 1 до 3 (индексы 1, 2, 3 включительно)
# В срезах Python верхняя граница исключается, поэтому указывается 4
slice_a = numbers[1:4]  # [20, 30, 40]
# Если срез трактуется как [1:3]: numbers[1:3] -> [20, 30]

# б) Первые три элемента (индексы 0, 1, 2)
slice_b = numbers[:3]   # [10, 20, 30]

# в) Элементы начиная с индекса 2 (до конца массива)
slice_c = numbers[2:]   # [30, 40, 50]
```

### Задание 6. Двумерный массив
> **Условие:** Для матрицы `grades` выведите оценку 88, всю вторую строку и весь третий столбец.
> ```python
> grades = np.array([[85, 90, 78],
>                    [70, 88, 92],
>                    [95, 81, 89]])
> ```

```python
import numpy as np

grades = np.array([[85, 90, 78],
                   [70, 88, 92],
                   [95, 81, 89]])

# Оценка 88 (строка с индексом 1, столбец с индексом 1)
grade_88 = grades[1, 1]     # 88

# Вся вторая строка (строка с индексом 1)
second_row = grades[1]       # [70, 88, 92]
# или: grades[1, :]

# Весь третий столбец (столбец с индексом 2)
third_col = grades[:, 2]     # [78, 92, 89]
```
